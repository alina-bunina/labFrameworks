Описание приложения

Веб-приложение представляет собой систему управления пользователями и их питомцами. Основные возможности приложения:

1. Регистрация пользователя
2. Авторизация пользователя
3. Просмотр питомцев
4. Добавление питомцев
5. Удаление питомцев
6. Редактирование информации о питомцах

Приложение работает с базой данных PostgreSQL, которая хранит таблицы profile (пользователи) и pet (питомцы).

Веб-приложение и база данных запускаются в отдельных Docker-контейнерах через Docker Compose.
